# EldredaTheta Launcher

This repository distributes updates for the main software.

## About

Theta Launcher is a desktop launcher for RR servers. It brings installing, updating, running and managing local server emulators into a single window, so you don't have to handle each step by hand.

## Features

- Guided installation of the supported servers and their patches, plus a clean uninstall option
- Start and stop servers with one click, with automatic closing of related processes
- Server updates from Git, with branch selection and a check that the update matches the game beta you have installed
- Import tab to bring in player data, including support for exported archives
- Edit tab to adjust character level, mindscapes, skills, weapon refinement, and disc main stats and substats
- Connection diagnostics, free disk space checks and an account reset option
- System tray integration with notifications, and single-instance protection
- Built-in self-update: the launcher checks this repository's releases on startup and updates itself

## Updates

Each release is tagged with the version number (for example, V1.11.0). The launcher reads the latest release from this repository and offers to update when a newer version is available.
